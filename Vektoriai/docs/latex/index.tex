\chapter{Studentų valdymo sistema}
\hypertarget{index}{}\label{index}\index{Studentų valdymo sistema@{Studentų valdymo sistema}}
Ši C++ programa leidžia\+:


\begin{DoxyEnumerate}
\item Pridėti naują studentą per vartotojo įvestį.
\item Nuskaityti studentų duomenis iš failo.
\item Spausdinti studentų sąrašą, pasirinkus galutinio balo skaičiavimo metodą (vidurkis arba mediana).
\item Išsaugoti studentų rezultatus į failą.
\item Generuoti didelius studentų duomenų failus (iki 10 milijonų įrašų).
\item Padalinti studentus į dvi kategorijas\+: „kietiakai“ ir „vargšiukai“ pagal jų rezultatus.
\item Testuoti didelių duomenų apdorojimo greitį (nuskaitymas, rūšiavimas, išsaugojimas).
\item Patikrinti Rule of Five principo įgyvendinimą klasėje \doxylink{class_student}{Student}.
\item Patikrinti, ar galima sukurti abstraktų objektą \doxylink{class_zmogus}{Zmogus}.
\item Baigti programos vykdymą.
\end{DoxyEnumerate}
